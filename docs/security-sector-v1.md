## Integrated problem-first flows
- House: gate/fence + camera + local NVR + alarm + backup + secure app access after owner approval.
- Farm: perimeter zones + gateways + local recording + independently powered radio/network; no assumed signal or power endurance.
- Shop: door/asset sensors + cameras + time-scoped user credentials + protected storage + incident reviews.
- School: safety and access with safeguarding, minimal recording, staff permissions and no uncontrolled student identification.
- Industrial site: cameras + perimeter + safe access control + environmental/power monitoring and maintenance records.
